# Thư mục Nhạc nền (Background Music)

- Bạn có thể thả 1 hoặc nhiều file nhạc nền không bản quyền (định dạng `.mp3` hoặc `.wav`) vào thư mục này.
- Bot sẽ tự động lấy file nhạc đầu tiên tìm thấy, lặp lại (loop) và giảm âm lượng xuống 15% để làm nhạc nền kịch tính/bí ẩn dưới giọng đọc.
- Nếu để trống thư mục này, bot vẫn sẽ dựng video với giọng đọc trong trẻo và âm thanh rõ ràng.
